# The Unanswered Media — Website

A responsive static website for The Unanswered Media.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and footer year

## Publish with GitHub Pages
1. Upload all three files to the root of the public repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main`, folder `/ (root)`, then **Save**.
5. Wait for GitHub Pages to deploy and use the public URL shown in Settings → Pages.
